# 经历挖掘访谈

求职前使用，不限行业和岗位。AI 一次问你一个问题：先确认你想做什么，再去查这类岗位现在实际在招什么样的人，然后把你简历上没写、但对求职有用的经历找出来。结束时给你两样东西：一份岗位规划，和一份岗位要求与你的经历的对照（哪些事可以写进简历、怎么写），可以自己留着改简历，也可以发给帮你做求职咨询的人。

应届生、在职想换方向的人都可以用。还没想好做什么也可以，访谈会先帮你收敛到一两个具体岗位。

## 怎么用

**方法一：发一句话（AI 能联网时）**

把下面这句话发给任意能联网的 AI 助手（ChatGPT、Claude、Kimi、豆包等）：

```
请读取 https://raw.githubusercontent.com/Minerva67/experience-match-interview/main/SKILL.md 的全部内容，并严格按照它和我对话，从「第 0 步：开场」开始。
```

**方法二：复制粘贴（方法一打不开链接时）**

打开 [SKILL.md 原文](https://raw.githubusercontent.com/Minerva67/experience-match-interview/main/SKILL.md)，全选复制，粘贴到一个新对话里发送。

**方法三：Claude 用户**

把本仓库作为 skill 安装，然后说「开始访谈」。

## 开始前请知道

- 请打开 AI 的联网搜索功能，访谈中它需要查招聘信息。不能联网时，它会请你贴 2–3 份想投的岗位描述。
- 全程大约 50–60 分钟、60 轮问答左右，可以中途停下，回到同一个对话接着聊。
- 很多问题和工作无关，照实回答即可。你觉得「这也算吗」的事，往往正是有用的。
- 中途会请你翻一下手机（常用 app、相册、收藏夹），请把手机放在手边。
- 有简历就先准备好，开场时贴进去；没有也可以直接开始。

## 你会得到什么

**一、岗位规划**
- 建议主投的岗位和备选岗位，以及为什么适合你
- 不建议投的岗位和原因
- 现在投什么、之后可以往哪走

**二、岗位要求和你的经历怎么对应**
- 每个岗位的要求清单（来自真实招聘信息），逐条标出你哪段经历能对上
- 可以写进简历的事项，每条附简历写法
- 简历上可以删掉的内容
- 还缺什么，2–4 周内可以怎么补
