# 经历挖掘访谈

求职前使用。AI 一次问你一个问题，帮你看清适合什么方向，并把简历上没写、但对求职有用的经历找出来。结束时生成一份摘要，可以自己留着改简历，也可以发给帮你做求职咨询的人。

适合想进 AI 或互联网公司的应届生和转行者，方向包括产品运营、产品经理、增长、数据分析。

## 怎么用

**方法一：发一句话（AI 能联网时）**

把下面这句话发给任意能联网的 AI 助手（ChatGPT、Claude、Kimi、豆包等）：

```
请读取 https://raw.githubusercontent.com/Minerva67/experience-match-interview/main/SKILL.md 的全部内容，并严格按照它和我对话，从「第 0 步：开场」开始。
```

**方法二：复制粘贴（方法一打不开链接时）**

打开 [SKILL.md 原文](https://raw.githubusercontent.com/Minerva67/experience-match-interview/main/SKILL.md)，全选复制，粘贴到一个新对话里发送。

**方法三：Claude 用户**

把本仓库作为 skill 安装，然后说「开始访谈」。

## 开始前请知道

- 全程大约 50–60 分钟，可以中途停下，回到同一个对话接着聊。
- 很多问题和工作无关，照实回答即可。你觉得「这也算吗」的事，往往正是有用的。
- 中途会请你翻一下手机（常用 app、相册、收藏夹），请把手机放在手边。
- 有简历就先准备好，开场时贴进去；没有也可以直接开始。

## 你会得到什么

- 适合的方向及依据
- 简历之外可以写进简历的经历，每条附一句简历写法
- 目标岗位的要求里，你已经有证据的和还缺的
- 针对你的初步建议
