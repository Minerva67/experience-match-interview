# 经历挖掘访谈

求职咨询前使用。AI 会一次问你一个问题，帮你看清适合什么方向，并把简历上没写、但对求职有用的经历找出来。结束时生成一份摘要，你复制发给咨询师。

适合想进 AI 或互联网公司的应届生，方向包括产品运营、产品经理、增长、数据分析。

## 怎么用

任何 AI 助手都可以（豆包、Kimi、DeepSeek、ChatGPT、Claude 等）。

1. 打开 [SKILL.md 原文](https://raw.githubusercontent.com/Minerva67/experience-match-interview/main/SKILL.md)，全选复制。
2. 新开一个对话，粘贴发送。
3. 按 AI 的提示贴上简历，然后逐个回答问题。
4. 访谈结束后，把 AI 生成的「前置信息摘要」完整复制，发给你的咨询师。

使用 Claude 的话，也可以把本仓库作为 skill 安装，然后说「开始访谈」。

## 开始前请知道

- 全程大约 50–60 分钟，可以中途停下，回到同一个对话接着聊。
- 很多问题和工作无关，照实回答即可。你觉得「这也算吗」的事，往往正是有用的。
- 中途会请你翻一下手机（常用 app、相册、收藏夹），请在手机在手边的时候做。
- 请在咨询开始前把摘要发出。

## 你会得到什么

- 适合的方向及依据
- 简历之外可以写进简历的经历，每条附一句简历写法
- 目标岗位的要求里，你已经有证据的和还缺的
- 针对你的初步建议（最终以咨询师的意见为准）
